## Data Collection Methodology

The dataset used in this project was built using real-world geospatial and demographic data from multiple publicly available sources.

### 1. OpenStreetMap (OSM) Data Collection

Business and location data were collected from **OpenStreetMap (OSM)** using the **Overpass API**, an open geospatial data service maintained by the global mapping community.

The collected Points of Interest (POIs) include:

* Restaurants
* Cafes
* Tea Shops
* Bakeries
* Offices
* Colleges
* Schools
* Hospitals
* Parks
* Bus Stops
* Other commercial establishments

### 2. Location Feature Engineering

For every business location, a spatial analysis was performed within a **500-meter radius** to generate business intelligence features such as:

* Footfall Index
* Nearby Restaurants Count
* Nearby Shops Count
* Nearby Offices Count
* Nearby Colleges Count
* Nearby Hospitals Count
* Nearby Parks Count
* Distance to the Nearest Competing Tea Brand

These features help estimate customer accessibility, competition intensity, and commercial activity around each location.

### 3. Economic and Demographic Enrichment

The location data were enriched with publicly available economic and demographic information, including:

* Estimated Commercial Rent
* Average Income of the Area
* Population Density
* Area Classification

These attributes provide additional context about the purchasing power and business potential of each locality.

### 4. Machine Learning Dataset

The final dataset combines geographic, commercial, demographic, and economic information into a structured dataset that serves as the input for a machine learning model.

The model predicts the **business success potential** of a selected location based on its surrounding environment, competition, accessibility, and market characteristics.

This approach enables entrepreneurs and business owners to evaluate locations using data-driven insights before making investment decisions.
